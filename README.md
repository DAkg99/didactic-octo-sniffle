# CS101: Movie Ticket Booking System

A terminal-driven movie booking platform written in Python. Robustly validates everything to prevent mishaps (e.g. double bookings).  
* **View current theatre schedule.** *Optionally search by date or title.*
* **Book tickets.** *A seat map is rendered for convenience. Discounts are handled automatically.*
* **View and cancel current bookings.** *Cancellations must abide by theatre policy.*  
* **Add or retire movies.** *Staff only.*
* **Update theatre schedule.** *Staff only.*
* **Update user bookings.** *Staff only. Note: Customers might get upset.*
* **View and export analytics.** *Staff only.*
* **Create manual backups of database.** *Staff only.*


## Setup

**Requires Python 3.10+**  
Clone via `git clone`. Run via `python main.py` in main directory.  

The repository comes with example data files `movies.json`, `showtimes.json`, and `bookings.json`. These can be cleared through the booking platform (requires staff access) or through a text editor. Make sure you are familiar with the format.
